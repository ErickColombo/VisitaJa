
# VisitaJá Frontend

The frontend uses plain HTML, CSS, and JavaScript.

- `index.html`: public visitor booking flow.
- `login.html`: administrator login.
- `admin.html`: protected administrator panel.

Start the backend first, then open `index.html` or serve this directory with a local static file server. The administrator login stores the JWT only in the browser session and sends it as a Bearer token to the protected API routes.
